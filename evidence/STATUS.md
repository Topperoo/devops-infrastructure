## Ограничения и само-ревью

- KVM/libvirt отличается от названных в PDF VirtualBox/Proxmox. Допустимость этой замены зависит от преподавателя.
- Облачный IAM не реализован. SSH/Unix-пользователи ограничивают доступ к гостю, но группа libvirt даёт широкие права на локальный гипервизор. Это явно описано в README.
- Обязательный по заданию sudo без пароля делает deployer административной учётной записью.
- Приватный SSH-ключ, tfvars, state и образ диска исключены из Git.
- Отрицательный сетевой тест проведён через временный внешний интерфейс ens-hwtest внутри гостя; это не тест из интернета. Namespace и интерфейс удалены.
- Исходная проблема Docker Snap на контроллере не исправлялась; Docker Engine внутри VM работает.
- В syslog сохранены ошибки первой загрузки контейнерных образов. Монитор считает их в часовом окне; текущие статусы Docker и healthcheck контейнеров исправны.
- Изображения — скриншоты страниц с сохранёнными логами. Это не скриншоты GUI-терминала. Полные txt-логи позволяют проверить содержимое.
- Репозиторий приватный; для сдачи преподавателю потребуется доступ.
